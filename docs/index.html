영상 대신 글로 보기

처음 한 번만 — 인터넷 창에서 chatgpt.com에 들어갑니다.

  1. 입력칸 아래 플러그인 → 왼쪽 스킬
  2. 오른쪽 위 추가 → 컴퓨터에서 업로드
  3. 받은 zip을 고릅니다.

쓸 때마다 — 새 채팅에서

  1. 입력칸 위가 Work인지 봅니다(앱은 꼭 눌러 주세요).
  2. +를 눌러 쓰던 한글 양식과 사진을 같이 올립니다.
  3. 「이 양식 그대로 결과보고서 만들어 줘」처럼 한 줄 씁니다.
  4. 답에 나온 파일을 받아 한글에서 ○○만 채우고, 다른 이름으로 저장 → 한글 문서(*.hwp)로 저장합니다.

새 판이 나오면 아래처럼 예전 도우미를 지우고 새로 받은 zip을 올리면 됩니다.

  1. chatgpt.com에서 입력칸 아래 플러그인 → 왼쪽 스킬로 갑니다.
  2. hwp document helper 오른쪽 [⋯] → 삭제 → 스킬 삭제를 누릅니다.
  3. 오른쪽 위 추가 → 컴퓨터에서 업로드로 새로 받은 zip을 올리고 완료를 누릅니다.
