AI에 한글 파일을 올리기 전에 이름·학번·연락처 같은 개인정보를 [이름1]처럼 가리고, AI가 만든 파일은 다시 원래대로 되돌립니다. 학생 얼굴이 나온 활동 사진도 AI에 올리지 않고, 여기서 문서의 [사진1] 자리에 한꺼번에 넣습니다.

인터넷으로 아무것도 보내지 않습니다. 이 화면은 지금 이 컴퓨터 안에서만 동작합니다.

1가릴 파일 넣기

AI에 올릴 한글 파일(.hwpx)을 여기에 끌어다 놓으세요 여러 개를 한꺼번에 넣어도 됩니다. 같은 사람은 모든 파일에서 같은 표시로 가려집니다.
    파일 대신(또는 함께) 글을 가리려면

    AI에게 보낼 요청 글이나 표를 붙여 넣으세요. 가린 글은 아래 3번에서 복사할 수 있습니다.

      3되돌리기

      1한글 파일과 사진 넣기

      [사진1] 같은 자리가 있는 한글 파일(.hwpx)과 넣을 사진을 함께 여기에 끌어다 놓으세요 사진은 여러 장을 한꺼번에 넣어도 됩니다. 사진은 이 컴퓨터 안에서만 다루고 인터넷으로 보내지 않습니다.

        2사진 순서 확인

        사진은 파일 이름 순서대로 [사진1]부터 차례로 들어갑니다. ↑↓로 순서를 바꾸고, 빼기로 뺄 수 있습니다(뒤의 사진이 한 칸씩 당겨집니다). 사진을 더 넣으면 맨 뒤에 붙습니다.

          사진 맞추는 방법

          3사진 넣은 파일 만들기

          이렇게 씁니다

          1. 가리기에서 AI에 올릴 한글 파일을 넣습니다. 이름·학번·연락처·이메일·주민등록번호·계좌번호·생년월일·주소를 찾아서 보여 줍니다.
          2. 가리지 않을 것은 체크를 빼고, 빠진 것은 '더 가릴 말'에 적은 뒤 가리기를 누릅니다.
          3. 「…_가림.hwpx」를 AI(Claude, ChatGPT 등)에 올려 문서를 만들게 합니다. 요청할 때 [이름1] 같은 표시는 그대로 두세요라고 한 줄 덧붙입니다.
          4. AI가 만든 파일을 내려받아 되돌리기에 넣고 되돌리기를 누르면, 원래 이름과 연락처가 들어간 「…_완성.hwpx」가 나옵니다.

          활동 사진 넣기

          1. AI에게 보고서를 부탁할 때 사진 6장 넣을 자리도 만들어 줘처럼 사진 장수를 함께 말합니다. 사진마다 설명(예: 1회 자기소개서 특강)을 적어 주면 사진 아래에 들어갑니다.
          2. AI가 만든 파일(가렸다면 되돌리기로 만든 「…_완성.hwpx」)과 사진을 사진 넣기에 함께 끌어다 놓습니다. 사진은 파일 이름 순서대로 [사진1]부터 들어가고, ↑↓로 순서를 바꿀 수 있습니다.
          3. 사진이 자리보다 많으면 자리를 같은 모양으로 늘려 모두 넣기, 적으면 남는 자리 지우기가 미리 골라져 있습니다. 다르게 하고 싶을 때만 바꿉니다. 늘린 자리는 한 쪽을 넘지 않게 표를 나눠 붙이고, 사진 설명 칸은 비워 둡니다.
          4. 사진 넣은 파일 만들기를 누르면 「…_사진.hwpx」가 나옵니다. 한글에서 열어 확인합니다.

          사진은 AI에 올리지 마세요. 학생 얼굴도 개인정보입니다. 사진 넣기는 이 컴퓨터 안에서만 동작합니다.

          꼭 지켜 주세요

          • 열쇠 파일(…_열쇠.json)에는 진짜 개인정보가 들어 있습니다. AI나 메신저, 메일로 보내지 마세요.
          • 자동으로 못 찾는 개인정보도 있습니다. 사진, 스캔한 서명, 그림 속 글자, 흔하지 않은 이름 같은 것들입니다. 3번의 '가린 결과 미리 보기'를 꼭 한 번 훑어보세요.
          • .hwp 파일은 한글에서 [파일] → [다른 이름으로 저장하기]를 누르고, 파일 형식을 HWPX 문서(*.hwpx)로 골라 저장한 뒤 넣으세요.
